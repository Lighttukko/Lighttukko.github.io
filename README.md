# Personal Website

This repository contains the code for my personal website, including both the frontend and backend components.

## Overview
I built this project as a personal web platform to combine a simple user-facing website with a backend service for handling user-submitted messages and persistent data storage. The project helped me gain practical experience with web development, backend structure, API design, and deployment.

## Features
- Personal website frontend built with HTML and CSS
- Python-based backend for handling application logic
- RESTful API support for user-submitted messages
- Persistent data storage for submitted content
- Basic input validation and error handling
- Separation between backend logic and data access for easier maintenance and future expansion
- Deployment to a cloud hosting platform

## Project Structure
- `index.html` – main frontend page
- `stylesheet.css` – website styling
- `BackEnd/` – backend logic and API handling
- `README.md` – project documentation
